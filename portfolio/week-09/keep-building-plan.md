# Week 9 — The Plan to Keep Building

## How to add the next case

1. Create a new folder under `portfolio/cases/<short-project-name>/`.
2. Start with the three-beat shape: **problem**, **what I did**, **what came of it**.
3. Add only public-safe evidence: an inspectable artifact, a screenshot that reveals no private data, and links a stranger can open.
4. Run the Portfolio Evidence Editor and resolve every missing-evidence or risky-claim flag.
5. Add a project card to the root portfolio and test its mobile order, keyboard path, and links.
6. Publish, then record the date and one known limitation.

What was implemented

Public benchmark

6,868 guide–candidate rows from the cited SITE-seq workbook, loaded at runtime and fingerprinted.

Leakage control

Stratified guide-grouped folds keep each intended guide inside one fold.

Two views

A transparent mismatch/seed baseline plus a position-aware random-forest activity ranker.

Audit trail

Results, SHA-256 provenance, bootstrap intervals, and limitations are saved with the run.

How the FlyRank ideas transfer

  1. Feature discipline: transcript k-mers become guide/candidate mismatch vectors, core and extended seed counts, and GC features.
  2. Nested tuning: the extended PAM-proximal window and weight are selected inside training folds only.
  3. Grouped validation: gene/cluster isolation becomes intended-guide isolation, preventing memorization of a guide's sequence context.
  4. Baseline first: a readable mismatch score is kept beside the refined ranker and legacy random forest.
  5. Evidence status: the ON/OFF classifier is marked as a sanity screen because exact matches make it structurally easy; the continuous activity task is the relevant ranking result.

Boundaries before biological use

This site does not provide a clinical recommendation, guide approval, genome-wide off-target search, or experimental protocol. For any real program, use the correct reference assembly, validated alignment/off-target software, cell-context evidence, independent review, and wet-lab confirmation. Scores should prioritize review only.

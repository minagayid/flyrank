A separate human CRISPR-Cas9 study

How well does a grouped off-target baseline rank benchmark pairs?

This page reports a completed, sequence-feature baseline on a public human CRISPR-Cas9 CIRCLE-seq benchmark. It is separate from FlyRank's SITE-seq study and the RefSeq transcript coding-status study. Only aggregate off-target results and public source links are shown here.

Source, labels, and method

The source is the Kaggle off-target dataset; the local source audit recorded the CIRCLE-seq archive as CC0: Public Domain. Its Indel/CIRCLE_seq.csv table contains 7,371 benchmark-positive rows and 577,578 candidate-negative rows. The source study describes a benchmark assembled from validated active sites and computational candidate negatives.

The classifier uses position-wise guide/target base-pair features with mismatch, gap, and sequence summaries. Read-count columns were excluded. A class-balanced SGD logistic classifier was evaluated with five guide-grouped folds. The benchmark has only 10 intended-guide groups, which constrains how broadly the fold results can generalize.

Negative-label meaning: a candidate absent from the validated-active set is not thereby proven biologically inactive. The high ROC-AUC does not establish genome-wide performance, calibrated probabilities, or safe guide selection.

Human reference and database links

The curated source inventory started from NCBI Taxonomy 9606 (Homo sapiens) and is a useful-link list, not an exhaustive export of every database. Genome packages for the two relevant assemblies were checked against NCBI MD5 manifests; compressed FASTA and GFF files also passed full gzip integrity reads. The reference sequences were used for source/build auditing; the reported off-target classifier itself ranks benchmark guide/target pairs and does not perform a genome-wide search.

Release scope and limitations

  • This page shares aggregate metrics and source links only. It contains no guide/target sequences, row-level predictions, training data, model weights, or NCBI genome files.
  • The on-target efficiency baseline is omitted from this public summary because separate reuse terms for the DeepCRISPR paper-data archive and the C-RNNCrispr held-out archive were not confirmed.
  • Only this CIRCLE-seq grouped benchmark is evaluated. No independent-study test, calibration, genome-wide alignment, cell-context transfer, or experimental validation is reported.
  • This is a research baseline for prioritizing further review. It is not a clinical recommendation, guide approval, biological safety probability, or replacement for validated computational and wet-lab review.

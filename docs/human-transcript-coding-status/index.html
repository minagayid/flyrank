A separate human transcript study

Can sequence features predict RefSeq coding-status labels?

A bounded comparison of simple nucleotide features for distinguishing human RefSeq NM_ from NR_ transcript accessions. This is an annotation-label prediction exercise, separate from FlyRank’s CRISPR SITE-seq study.

At the 0.5 classification threshold, the TF-IDF confusion matrix (true rows, predicted columns; NR_=0, NM_=1) was [[412, 204], [130, 494]]. Across five distinct development-only validation splits, AUPRC ranged from 0.749 to 0.785; this is validation sensitivity, not repeated test evaluation.

Source and label audit

The notebook downloaded NCBI Datasets package rna,gff3 for human assembly GCF_000001405.40 (GRCh38.p14), pinned to annotation release GCF_000001405.40-RS_2025_08. It parsed 93,550 records: 69,783 NM_ and 23,767 NR_. It found no duplicate base accessions, duplicate accession.version rows, missing GeneIDs, invalid sequence bases, or direct transcript-GFF key disagreements with accession prefixes.

Parent-gene biotype was audited separately from transcript labels. For 7,727 of the 23,767 NR_ records (32.5%), the parent gene’s GFF biotype was protein_coding. That is a transcript-versus-gene annotation-level difference; it is not proof by itself that either label is wrong.

Leakage-aware evaluation

After a full-source audit, the notebook sampled up to 3,000 transcripts per label. MMseqs2 clustered every sampled transcript at 80% nucleotide identity and 80% coverage. A connected-component union joined records sharing either an NCBI GeneID or a sequence cluster. Those components were split into train (3,816 records), validation (944), and test (1,240). The notebook asserts zero pairwise overlap for GeneID, sequence-cluster ID, connected-component ID, and exact-sequence SHA-256.

All preprocessing and model selection stayed within training/validation data. The TF-IDF regularization parameter was selected by validation AUPRC; the primary test was evaluated once. Bootstrap intervals resample connected components rather than transcript rows.

What the errors say

  • Errors were more frequent for NR_ transcripts (33.1%) than NM_ transcripts (20.8%).
  • Among held-out records with parent-gene biotype protein_coding (n=825), error was 34.1%; among those with biotype lncRNA (n=310), error was 13.5%.
  • By transcript-length quartile, error was 17.7%, 29.0%, 33.5%, and 27.4%. The model did not perform uniformly across sequence groups.

Some biotype strata are small: for example, the reported miRNA group has 55 test records. Its observed zero errors should not be interpreted as reliable generalization.

Limits and next step

  • NM_/NR_ are operational RefSeq labels, not independent experimental ground truth about translation or function.
  • The modeling set is balanced while the parsed source is 74.6% NM_; test metrics therefore do not estimate performance at the source population’s natural label prevalence.
  • This is one annotation snapshot and one 80% identity/80% coverage grouping rule. No multi-threshold robustness sweep, independent RefSeq release, or external cohort was run.
  • FLIP2, CRISPR/SITE-seq, variants, clinical use, and wet-lab claims are outside this study.

A bioinformatics researcher should review the label semantics, transcript/GeneID joins, clustering rule, and error analysis before stronger claims are made.
